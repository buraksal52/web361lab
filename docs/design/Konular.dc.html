Sınıf ve id seçici

Bir stili sayfadaki belirli etiketlere uygulamak için etiketleri adlandırırız. Bu adlandırmanın iki yolu var: sınıf ve id.

KısacaSınıf birçok etikete verilebilir, id ise sayfada bir kez kullanılır.

Sınıf seçici

Sınıf, HTML'de class özelliğiyle verilir. CSS'te nokta ile seçilir. Aynı sınıfı birden fazla etikete verebilirsin.

KOD ÖRNEĞİHTML + CSS
.kart { padding: 16px; } <div class="kart">Birinci kutu</div> <p class="kart">Aynı sınıf</p>

Id seçici

Id, bir etikete özel isimdir ve CSS'te diyez işaretiyle seçilir. Bir id sayfada yalnızca bir etikette bulunmalı.

KOD ÖRNEĞİHTML + CSS
#baslik { color: #112e6e; } <h1 id="baslik">Merhaba Web</h1>
